## ⚠️ COMMON ISSUES & SOLUTIONS

### Problem: Can't find the Admin button on home page
**Solution**: 
- Scroll up - it's at the top in a golden box
- Or go directly to: `http://localhost:3000/admin-login`

### Problem: Wrong password error
**Solution**:
- Make sure you're using: `Admin@123` (Case sensitive)
- Try "Use Demo Credentials" button for auto-fill

### Problem: Page keeps redirecting to login
**Solution**:
- Make sure you're logged in
- Try clicking "Use Demo Credentials" and sign in again
- Clear browser cache (Ctrl+Shift+Delete)

### Problem: Development server not running
**Solution**:
- Run: `npm start` in the project folder
- Wait 30 seconds for compilation
- Refresh the page
